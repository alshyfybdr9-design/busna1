# اختبار الضغط

يحاكي ذروة الصباح لمنصة بحجم **300 ألف طالب** على قاعدة بيانات منفصلة (`busna_load`) لا تمس بيانات التطوير.

## الخطوات

```bash
# 1) تعبئة البيانات (≈ دقائق، ≈ 6–8 GB): 301 جهة (منها شركة نقل بـ30 ألف طالب)، 6,000 باص،
#    240 ألف ولي أمر، رحلات 3 أيام سابقة + اليوم، ونقاط مواقع كل 10 ثوانٍ
npm -w apps/api run loadtest:seed

# 2) تشغيل الخادم المبني على قاعدة الاختبار (المنفذ 4100)
npm -w apps/api run loadtest:serve

# 3) المحاكاة (في نافذة أخرى)
LT_API=http://127.0.0.1:4100 LT_STEPS=0.05,0.1,0.2,0.35,0.5 LT_STEP_SEC=30 npm -w apps/api run loadtest:run
```

## ما تحاكيه الأداة

| المستخدم | السلوك | المعدل |
|---|---|---|
| السائق | نقطة موقع كل 10 ث + تسجيل صعود أحيانًا | ≈ 0.1 طلب/ث |
| ولي الأمر النشط | قائمة الأبناء كل 20 ث، حالة الطفل (نصفهم على شاشة التتبع)، الإشعارات كل 60 ث | ≈ 0.1 طلب/ث |

الذروة الكاملة = 6,000 سائق + 50,000 ولي أمر فاتحين التطبيق في نفس اللحظة ≈ **5,600 طلب/ث**.
كل خطوة نسبة من هذه الذروة. المعدل مفتوح: الطلبات تُرسل بالمعدل المطلوب حتى لو بطؤت الردود.

متغيرات: `LT_PEAK_DRIVERS`، `LT_PEAK_PARENTS`، `LT_STEPS`، `LT_STEP_SEC`، `LT_MAX_INFLIGHT`، `LT_STOP_P95_MS`، `LT_OUT` (ملف JSON للنتائج).
حجم البيانات: `LT_STUDENTS`، `LT_BIG_TENANT`، `LT_PER_TENANT`، `LT_HISTORY_DAYS`.

النتائج وتحليلها في [`RESULTS.md`](RESULTS.md).
