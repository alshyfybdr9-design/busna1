# باصنا — Busna

منصة SaaS سعودية لإدارة النقل. الوحدة الأولى: **النقل المدرسي** للمدارس الخاصة والحكومية.

- **لوحة إدارة المدرسة** — متابعة مباشرة للباصات والرحلات والطلاب والتقارير.
- **تطبيق السائق** — بدء الرحلة، تسجيل الحضور، الوصول، الإنهاء، ومشاركة الموقع أثناء الرحلة فقط.
- **تطبيق المشرف** — الحضور، الملاحظات، البلاغات، والتواصل مع أولياء الأمور.
- **تطبيق ولي الأمر** — حالة الأبناء، تتبع الباص عند وجود الابن داخله فقط، الإشعارات، والمساعد الذكي.

## التقنيات
Next.js · Supabase (Auth, PostgreSQL, RLS, Realtime) · MapLibre
